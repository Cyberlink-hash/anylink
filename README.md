# AnyLink · 定制增强版

本仓库基于 [bjdgyc/anylink](https://github.com/bjdgyc/anylink) 二次开发，主要围绕 LDAP / LLDAP 用户管理、OTP 开通、网络访问控制和 DNS 配置进行优化。

感谢原作者 **bjdgyc** 及所有上游贡献者对 AnyLink 的开发与维护，为这些改进提供了基础。本仓库是独立维护的衍生版本，VPN 协议实现和基础能力来自上游；以下仅介绍本仓库新增或改进的内容。

许可证沿用 [AGPL-3.0](LICENSE)。原项目介绍及基础部署文档请参阅[上游仓库](https://github.com/bjdgyc/anylink)。

## 网络策略与访问控制

新增可复用的网络策略，在同一用户组内实现不同用户的访问权限管理，无需为了少量权限差异拆分大量用户组。

- **用户选择**：支持搜索并多选用户名，无需手动填写用户名列表。
- **连接来源条件**：支持按 VPN 连接来源 IP 或 CIDR 网段匹配。来源地址是服务端看到的客户端连接地址，通常为公网出口 IP。
- **目标访问控制**：支持按目标 IPv4 地址或网段、协议、端口设置允许或拒绝规则。
- **跨组复用**：同一网络策略可被多个用户组引用，每个组可调整策略关联顺序。
- **顺序匹配**：先匹配用户名和来源条件，再按顺序匹配目标访问规则；未命中时继续匹配后续策略，最终回到组原有的权限控制规则。
- **路由边界**：网络策略不能扩大最终下发的路由范围，排除路由优先拒绝。不改变原有“启用的用户策略路由覆盖组路由”逻辑，也不将两者取并集。
- **DNS 与分片处理**：启用网络策略时，DNS 53 端口的原有放行例外也受路由边界约束，并拒绝 IPv4 分片，避免分片绕过端口检查。
- **配置保护**：被用户组引用的网络策略不能直接删除；保留旧版条件引用的兼容处理。

例如，同组的张三可以不限连接来源访问管理台；李四则先匹配固定来源允许规则，再由拒绝规则兜底，实现仅从指定出口 IP 连接时才能访问管理台。两人的访问范围均不能超出最终路由权限。

网络策略需关联到实际登录的用户组才会生效，多组登录场景应分别关联。来源条件不满足表示跳过该策略，并不自动拒绝访问；限制访问时应配置明确的拒绝规则。配置修改后重连生效，当前目标访问规则针对 IPv4。

## LDAP / LLDAP 兼容与用户同步

### LLDAP 用户组兼容

- 在 LDAP 不支持现有 memberOf 查询方式时，回退检查 groupOfUniqueNames / uniqueMember 或 groupOfNames / member，提高 LLDAP 用户组认证兼容性。
- 外部认证成功后维护用户记录与组归属，并记录认证类型；LDAP 用户必须先由管理员同步开通，不再通过首次登录自动建档。
- 定时检查已有 LDAP 用户是否仍符合组成员要求，不再符合时停用。

### 手动同步 LDAP 用户

- 管理员可在用户列表主动触发同步，按已有的 LDAP 用户组导入用户，无需等待用户首次登录 VPN。
- 登录、LDAP 同步、后台新增／修改和 Excel 导入统一使用小写用户名；保存时忽略大小写检查重复，保留原账户的 OTP 和停用状态。
- SQLite 增加数据库层的用户名小写校验，结合原有唯一索引，防止并发重复创建账户。升级前请先在旧版本清理重复、大写及带首尾空格的用户名；检测到这些旧数据会停止启动，不自动改名、合并或删除。其他数据库仍使用应用层规范化与原有唯一约束。
- 同步支持新增用户、更新资料和补充组归属，不因一次同步结果删除用户或移除组。
- 同步只读取 LDAP，不修改 LDAP 中的用户和组。
- 多个用户组共用同一套 LDAP、相同用户名代表同一人时，复用本地用户记录并补充组归属。
- 同名非 LDAP 用户会跳过，避免覆盖其他认证类型的账户。

### 姓名与邮箱同步

- 从 LDAP 获取 displayName 和 mail，更新 AnyLink 中的姓名与邮箱。
- LDAP 非空资料覆盖本地对应字段，空邮箱不清空已有邮箱。
- displayName 为空时，使用用户名作为显示名称。

### 新增用户 OTP 与邮件

- 手动同步新增的 LDAP 用户默认开启 OTP，并尝试向用户邮箱发送一次开通邮件。
- 已有用户保留原 OTP 开关、密钥和停用状态，不因同步重置或自动启用。
- 邮件发送失败不回滚用户创建，同步结果单独提示失败；再次同步不重复发信，可在用户编辑页补发。
- 沿用现有“独立 OTP 认证”设置，邮件发送使用已配置的 SMTP 服务。

## 用户管理体验与批量操作

- 修复搜索输入后按回车不生效的问题。
- 修复翻页时丢失搜索条件的问题。
- 用户管理、网络策略用户搜索及在线用户的用户名搜索忽略大小写。
- 增加用户组、认证类型、启用状态和 OTP 状态筛选。
- 支持对当前页勾选的用户批量执行五类操作：启用、停用、开启 OTP、关闭 OTP、删除。
- 批量停用时同时断开用户的在线连接。
- 在外部认证、会话创建及隧道重连时补充本地用户状态检查，使停用状态得到执行。

## 用户组复制

- 支持复制现有用户组，减少重复配置工作。
- 自动生成不重复的组名，方便基于现有组建立相似配置。

## Split DNS 配置优化

- 为用户组和用户策略增加内网域名、关闭全局 DNS 的配置与校验。
- 规范域名输入，减少格式差异导致的配置问题。
- 修正 Split DNS 配置下发，以及用户策略覆盖过程中的相关行为。

## DTLS 与登录错误提示

- 服务端关闭 DTLS 时，不再向客户端下发 DTLS 连接头。
- 对返回客户端的认证错误进行脱敏，避免直接暴露底层 LDAP 连接信息。此项针对客户端提示，不代表所有服务端日志均已脱敏。
